رابط الحجز الإلكتروني المباشر للطلاب

هذا الرابط مُفعّل ويعمل فعلياً: شاركه مع الطلاب ليقوموا بتعبئة استمارة الحجز بأنفسهم، وستصلك طلباتهم مباشرة في الجدول أدناه.

هام جداً: لسه مفيش قاعدة بيانات مشتركة متصلة. يعني حجز الطالب من موبايله الشخصي مش هيوصل لوحتك دلوقتي — اتبع الخطوات تحت لربط قاعدة بيانات مجانية (Supabase) وتفعيل الوصول من أي جهاز.

لتفعيل وصول الحجوزات من أي جهاز (خطوة تُعمل مرة واحدة فقط، عن طريق Supabase):
  1. افتح supabase.com وسجّل حساب مجاني (بريد إلكتروني عادي، بدون تفعيل إجباري لخطوتين التحقق).
  2. اعمل New Project (اختر اسم وكلمة سر لقاعدة البيانات واحفظها في مكان آمن).
  3. من القائمة الجانبية: Table Editor ← New Table، اعمل جدولين (وعطّل خيار "Enable Row Level Security" وقت إنشاء كل واحد):
    • جدول اسمه booking_requests بالأعمدة: name (text), stage_id (int8), group_id (int8), phone (text), parent_phone (text)
    • جدول تاني اسمه center_state بالأعمدة: id (int8، خليها Primary Key)، payload (jsonb)، updated_at (timestamptz)
  4. من القائمة الجانبية: Project Settings ← API، انسخ Project URL وanon public key.
  5. ابعتهملي هنا في الشات وأنا أدخلهم في الكود وأديك الملف جاهز، أو افتح ملف البرنامج بمحرر نصوص وابحث عن SUPABASE_URL وSUPABASE_ANON_KEY والصق القيم بدل الرموز ★★★.
لو محتاج مساعدة في أي خطوة من دول، ابعتلي وهساعدك خطوة بخطوة.

إعدادات الرسائل الجماعية على تليجرام

خطوات تفعيل الإرسال الجماعي على تليجرام:
  1. افتح تطبيق تليجرام وابحث عن @BotFather.
  2. أرسل له الأمر /newbot واتبع الخطوات لإنشاء بوت جديد، وسيعطيك Bot Token — الصقه في الحقل بالأعلى واحفظه.
  3. أنشئ مجموعة تليجرام لكل مجموعة دراسية عندك، وأضف كل أولياء الأمور/الطلاب فيها.
  4. أضف البوت الذي أنشأته كعضو في مجموعة التليجرام هذه.
  5. احصل على Chat ID الخاص بالمجموعة (يمكن ذلك عبر إضافة بوت مساعد مثل @RawDataBot للمجموعة مؤقتاً وسيعرض لك الرقم، ثم يمكنك حذفه).
  6. اذهب لتبويب "المجموعات الدراسية" وعدّل كل مجموعة، وألصق الـ Chat ID في حقل "معرف تليجرام".
  7. بعد ذلك سيظهر زر "رسالة جماعية" فعّال أمام كل مجموعة يرسل لجميع أعضائها فوراً.
